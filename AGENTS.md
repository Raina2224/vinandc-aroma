# AGENTS.md — Agent instructions for Vin&c Aroma repo

Purpose
- Short, actionable guidance to help AI coding agents run, test, and modify this repository quickly.

Quick run & test commands
- Backend (FastAPI): run from repo root or `backend` directory:

```bash
# from repo root
python -m uvicorn backend.server:app --reload --host 0.0.0.0 --port 8000

# or from backend/
uvicorn server:app --reload --port 8000
```

- Frontend (CRA + craco):

```bash
cd frontend
yarn install
yarn start
# build: yarn build
# test: yarn test
```

- Backend tests (pytest):

```bash
cd backend
pytest -q
```

Environment & important variables
- Backend expects a `.env` file in `backend/` with at least:
  - `MONGO_URL` — MongoDB connection string
  - `DB_NAME` — database name
  - `STRIPE_API_KEY` — stripe key (used by checkout integration)
  - `JWT_SECRET` — secret used to sign tokens
- The repo seeds a default admin on startup: `admin@vincaroma.com` / `Admin@123`.
- OTP endpoints use a mock OTP `123456` for demo/testing (see `backend/server.py`).

Key files & conventions
- API server: [backend/server.py](backend/server.py#L1-L40) — FastAPI app and routes. Seed data and auth helpers live here.
- Frontend: [frontend/package.json](frontend/package.json#L1-L40) — scripts use `craco` and `yarn`.
- Tests: `backend/tests/` — run with `pytest` from the `backend` directory.

Editing guidelines for agents
- Prefer small, focused PRs. Keep backend changes backwards-compatible with the FastAPI app shape.
- When adding new endpoints, update or add tests under `backend/tests/`.
- Do not commit secrets or `.env` files. If you need to run locally, document required env vars in PR description.

Notes & gotchas
- The backend uses an asynchronous MongoDB client (`motor`) — use async test clients or run integration tests against a test Mongo instance.
- Frontend uses Yarn v1 (see `packageManager` in `frontend/package.json`). Use `yarn` to run scripts by default.
- The repo's README is intentionally minimal; link to files instead of duplicating existing documentation.
